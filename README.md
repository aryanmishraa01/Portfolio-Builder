# Portfolio Builder

Portfolio Builder is a web application that helps users create and manage their own portfolio.

Users can create an account, add their personal details and projects, preview their portfolio, and share it using a public link.

## Features

- User registration and login
- Create and edit portfolio details
- Add, edit and delete projects
- Live portfolio preview
- Public portfolio page
- Responsive design

## Tech Stack

- React.js
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT & bcrypt
